# 기본동작 테스트 케이스

> **테스트 환경:** 트릭컬 리바이브 ver.1.6.20 / Galaxy Wide7 / Android 16 / One UI 8.5  
> **테스트 일자:** 2026-08-20

> **각 사도 위치는 화면 기준 왼쪽부터 1~5번으로 구분했습니다.**

## 1. 테스트 목적

로그인 화면에서 안내된 방식으로 사도의 볼을 Drag하여
정상적으로 로그인 및 게임 진입이 가능한지 검증합니다.

## 3. 테스트 결과

### TC-BAS-006 — 위치별 사도 볼 Drag

**결과: N/T**

1~4번 위치의 사도는 볼을 Drag하여 정상적으로 Login Trigger가 발생했습니다.

5번 위치의 사도는 화면 우측 끝에 위치하여 볼을 정상적으로 Drag 및 Touch 할 수 없는 현상이 확인되었습니다.

> ※ 현재 테스트 환경에서 확인된 결과이며, 특정 기기 환경에 의한 현상인지 여부는 추가적인 기기 비교 테스트가 필요합니다.
