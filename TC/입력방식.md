# 입력 방식 테스트 케이스

> **테스트 환경:** 트릭컬 리바이브 ver.1.6.20 / Galaxy Wide7 / Android 16 / One UI 8.5  
> **테스트 일자:** 2026-08-20

## 테스트 목적

로그인 화면에서 사용자의 입력 방식에 따른 Login Trigger 발생 여부와
Trigger가 발생하는 시점을 확인합니다.

게임에서는 Drag를 통한 로그인을 안내하고 있으나(볼을 잡아당겨서 시작하기),
실제 입력 방식에 따라 Login Trigger가 어떻게 동작하는지 확인하여
안내된 조작 방식과 실제 동작의 차이를 검증합니다.

## 테스트 케이스

| TC ID | 테스트 항목 | 테스트 절차 | 기대 결과 | 결과 |
|---|---|---|---|---|
| TC-INP-001 | Drag 입력 | 캐릭터 디자인상 볼로 표현된 영역을 잡고 Drag한 후 손을 뗀다. | 손을 뗀 후 Login Trigger가 발생하고 로그인 과정이 시작된다. | PASS |
| TC-INP-002 | Tap 입력 | 캐릭터 디자인상 볼로 표현된 영역을 짧게 Tap한 후 손을 뗀다. | 손을 뗀 후 Login Trigger가 발생하는지 확인한다. | PASS |
| TC-INP-003 | 입력 유지(Hold) | 볼 영역을 Touch한 상태에서 손을 떼지 않고 일정 시간 유지한다. | 입력을 유지하는 동안 Login Trigger가 발생하지 않는다. | PASS |
| TC-INP-004 | Drag 상태 유지 | 볼 영역을 Drag한 상태에서 손을 떼지 않고 유지한다. | Drag 상태를 유지하는 동안 Login Trigger가 발생하지 않는다. | PASS |
| TC-INP-005 | 입력 종료 시점 확인 | 볼 영역을 Touch 또는 Drag한 후 손을 뗀다. | 손을 뗀 시점에 Login Trigger가 발생한다. | PASS |

---

## 테스트 결과

- Touch 또는 Drag 입력을 종료하여 손을 뗀 시점에 Login Trigger가 발생하는 것을 확인했습니다.
