# 사운드 테스트 케이스

> **테스트 환경:** 트릭컬 리바이브 ver.1.6.20 / Galaxy Wide7 / Android 16 / One UI 8.5  
> **테스트 일자:** 2026-08-20

> **각 사도 위치는 화면 기준 왼쪽부터 1~5번으로 구분했습니다.**

## 1. 테스트 목적

로그인 화면에서 발생하는 배경음악, 볼 입력 효과음 및 사도 Voice가
각 입력 동작에 따라 정상적으로 재생되는지 확인합니다.

로그인 화면 진입부터 볼 입력 및 입력 종료까지
각 인터랙션에 대응하는 사운드가 정상적으로 재생되는지 검증합니다.

---

## 2. 테스트 케이스

| TC ID | 테스트 항목 | 테스트 절차 | 기대 결과 | 결과 |
|---|---|---|---|---|
| TC-SND-001 | 로그인 화면 BGM | 게임을 실행하여 로그인 화면에 진입한다. | 로그인 화면 진입 후 로그인 화면 BGM이 정상적으로 재생된다. | PASS |
| TC-SND-002 | 볼 입력 효과음 | 사도의 볼을 Touch 또는 Drag한다. | 볼을 입력하는 동안 볼을 당기는 효과음이 정상적으로 재생된다. | PASS |
| TC-SND-003 | 입력 종료 Voice | 볼을 Touch 또는 Drag한 후 손을 뗀다. | 손을 뗀 시점에 입력한 사도의 Voice가 정상적으로 재생된다. | PASS |
| TC-SND-004 | 사도별 Voice 확인 | 1~5번 위치의 사도 및 다양한 사도의 볼을 각각 입력한 후 손을 뗀다. | 입력한 사도에 대응하는 Voice가 정상적으로 재생된다. | N/T |
| TC-SND-005 | 입력 방식별 효과음 | 볼을 Touch하는 경우와 Drag하는 경우를 각각 테스트한다. | Touch와 Drag 입력 모두 볼 입력 효과음이 정상적으로 재생된다. | PASS |
