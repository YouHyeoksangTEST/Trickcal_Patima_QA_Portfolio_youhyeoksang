# Hit Area 테스트 케이스

> **테스트 환경:** 트릭컬 리바이브 ver.1.6.20 / Galaxy Wide7 / Android 16 / One UI 8.5  
> **테스트 일자:** 2026-08-20

> **각 사도 위치는 화면 기준 왼쪽부터 1~5번으로 구분했습니다.**

## 1. 테스트 목적

로그인 화면에 등장하는 사도들을 대상으로
볼, 볼 주변 영역, 캐릭터 파츠 및 배경 영역의 입력 여부를 확인합니다.

사도는 랜덤으로 선정되므로 다양한 사도를 대상으로 테스트했으며,
7월 30일에 등장한 신규 사도인 에슈르(마도)는 큰 캐릭터 파츠를 가지고 있어
대표적인 테스트 및 캡처 대상으로 활용했습니다.

## 2. 테스트 케이스

| TC ID | 테스트 항목 | 테스트 절차 | 기대 결과 | 결과 |
|---|---|---|---|---|
| TC-HIT-001 | 볼 자체 입력 | 사도의 볼 영역을 Drag한다. | 캐릭터 디자인상 볼로 표현된 영역에서 Login Trigger가 발생한다. | PASS |
| TC-HIT-002 | 볼 인접 영역 입력 | 볼에서 조금 벗어난 인접 영역을 Drag한다. | 볼 주변의 일정 영역에서도 해당 볼의 Login Trigger가 발생한다. | PASS |
| TC-HIT-003 | 비입력 캐릭터 영역 | 눈, 머리, 몸 등 볼을 제외한 캐릭터 파츠를 Drag한다. | Login Trigger가 발생하지 않는다. | PASS |
| TC-HIT-004 | 비입력 배경 영역 | 사도와 볼에서 떨어진 배경 영역을 Drag한다. | Login Trigger가 발생하지 않는다. | PASS |
| TC-HIT-005 | 배경 및 인접 영역 구분 | 볼과 가까운 배경 영역과 볼에서 떨어진 배경 영역을 각각 Drag한다. | 볼과 가까운 영역은 인접 볼의 Hit Area로 인식되고, 떨어진 배경은 입력되지 않는다. | PASS |
| TC-HIT-006 | 가려진 사도 입력 | 다른 사도의 큰 파츠에 의해 일부가 가려진 사도의 볼을 Drag한다. | 가려진 상태에서 대상 사도의 볼 입력 영역이 어떻게 판정되는지 확인한다. | N/T |

## 3. 테스트 결과

### TC-HIT-006 — 가려진 사도 입력

**결과: N/T**

3번 위치의 큰 캐릭터 파츠를 가진 사도에 의해 2번과 4번 위치의 사도가 일부 가려진 상태에서 입력을 확인했습니다.

2번 위치의 사도는 일부가 가려진 상태에서도 정상적으로 볼 Drag가 가능했습니다.

4번 위치의 사도는 볼 영역을 정상적으로 Drag할 수 없었습니다.
